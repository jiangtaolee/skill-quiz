# 技能鉴定刷题 · 部署与安装说明

> 这是一个用网页做成的「刷题 App」：电脑上双击就能用；放到网上后，iPhone 用 Safari「添加到主屏幕」，
> 就跟普通 App 一样全屏使用，**联网加载一次之后完全离线也能刷题**。
> 学习记录（答题、错题、收藏、统计）只保存在你自己的设备里，不会上传到任何服务器。

---

## 0. 先认识这些文件（整个文件夹 = 一个网站）

| 文件 / 文件夹 | 作用 | 能删吗 |
|---|---|---|
| `index.html` | 入口页面 | ❌ 不能 |
| `styles/app.css` | 界面样式 | ❌ 不能 |
| `src/questions.js` | 题库（600 题全部在这里） | ❌ 不能 |
| `src/srs.js` | 艾宾浩斯复习算法 | ❌ 不能 |
| `src/store.js` | 学习记录存储 | ❌ 不能 |
| `src/app.js` | 界面与交互逻辑 | ❌ 不能 |
| `icons/` | App 图标（5 个尺寸） | ❌ 不能 |
| `manifest.webmanifest` | PWA 应用信息（名称、图标、主题色） | ❌ 不能 |
| `sw.js` | Service Worker（离线缓存） | ❌ 不能 |
| `dist/技能鉴定刷题.html` | 单文件版（可选，给不会部署的场景用） | 可重新生成 |
| `tools/`、`docs/` | 开发用脚本和文档 | 部署时可以不传 |
| `data/`、`tests/`、`.docx` 题库文件 | 开发用 | 部署时可以不传 |

**要点：部署时整个文件夹原样上传，`index.html` 必须位于网站根目录（或子目录的第一层）。**
文件之间的引用全部使用相对路径，所以放在子目录（例如 `https://example.com/skillquiz/`）也能正常工作。

## 1. 电脑上先看效果（本地预览）

### 1.1 最简单：直接双击 `index.html`

- ✅ 秒开，能刷题，学习记录保存在浏览器里；
- ⚠️ 这种方式是 `file://` 打开，浏览器**不允许注册 Service Worker**，所以没有离线缓存，也不能「安装成 App」；
- ⚠️ 个别浏览器对本地文件的 `localStorage` 有限制，学习记录可能不保存 → 重要数据请及时用「设置 → 导出备份」；
- 适合：快速检查页面、给同事看效果。

> 如果双击后是白屏：按 `F12` 打开浏览器控制台看报错，最常见原因是文件被单独移动、`src/` 或 `styles/` 文件夹没和 `index.html` 放在一起。

### 1.2 更像真实环境：本机起一个 http 服务

`localhost` 属于浏览器的「安全上下文」，可以完整测试 Service Worker 和离线能力。

在**项目文件夹里**打开命令行（Windows：在地址栏输入 `cmd` 回车；macOS：终端 `cd` 进入），执行其中一条：

```bash
# 有 Python 3 的话（推荐，最简单）
python -m http.server 8000

# 或者有 Node.js 的话
npx serve .
# 或
npx http-server -p 8000
```

然后用浏览器打开：

- `http://localhost:8000`（Python）
- `http://localhost:3000`（`npx serve` 默认端口，以终端提示为准）

测试离线：先正常打开一次 → 停留几秒让缓存完成 → 按 `F12` → `Application` → 勾选 `Service Workers` 里的 `Offline`（或直接断网）→ 刷新，仍然能打开说明离线成功。

> 改完代码后：普通刷新即可；如果发现还是旧内容，关闭标签页重新打开，并按下一节的「更新版本」说明修改缓存版本号。

### 1.3 用手机在局域网里预览（不推荐用于正式使用）

电脑起服务后，手机连同一个 Wi-Fi，访问 `http://电脑局域网IP:8000`。

- ✅ 能刷题，数据也能保存；
- ⚠️ 但 `http://192.168.x.x` **不是安全上下文**，Service Worker 不会注册 → **没有离线缓存、不能添加到主屏幕**，属于正常降级；
- 想在手机上获得完整体验，请按第 2 节部署到 https 网站。

## 2. 部署到静态托管（得到 https 网址，iPhone 才能「安装」）

PWA 的离线缓存和「添加到主屏幕」都要求 **https**。下面三种方式任选一种，都免费、都够用。

> 共同要求：
> 1. 上传的是**整个项目文件夹**（至少包含 `index.html`、`styles/`、`src/`、`icons/`、`manifest.webmanifest`、`sw.js`）；
> 2. `index.html` 在网站根目录（或子目录第一层）；
> 3. 不需要配置构建命令、不需要安装依赖（纯静态网站）；
> 4. 文件名大小写必须一致（`styles/app.css` 不能写成 `Styles/app.css`）。

### 2.1 Netlify Drop（最快，不用 git，适合非程序员）⭐ 推荐

1. 浏览器打开 <https://app.netlify.com/drop>；
2. 把**整个项目文件夹**拖进虚线框；
3. 等几十秒，会得到一个 `https://随机名字.netlify.app` 的网址；
4. 打开这个网址，能正常刷题就成功了。

**以后更新**：把文件夹重新拖进同一个站点的 Deploys 页面（或用站点菜单里的 Deploy manually），网址不变，内容更新。

### 2.2 GitHub Pages（免费、有版本记录）

1. 在 GitHub 新建一个仓库（Public 即可）；
2. 把项目文件上传到仓库根目录（网页端 `Add file → Upload files` 直接拖文件夹也行）；
3. 进入仓库 `Settings → Pages`；
4. `Source` 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，点 `Save`；
5. 等 1～2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。

> 放在 `/<仓库名>/` 这样的子目录里完全没问题，因为所有路径都是相对的。
> 如果更新后看不到变化，等一两分钟，或按 `Ctrl+F5` 强制刷新。

### 2.3 Vercel

- **网页方式**：<https://vercel.com> → `Add New… → Project` → 导入 Git 仓库 →
  `Framework Preset` 选 **Other** → `Build Command` 留空 → `Output Directory` 填 `.` → `Deploy`；
- **命令行方式**：在项目文件夹执行 `npx vercel --prod`，按提示一路回车（`Output Directory` 选当前目录）。

部署成功后会得到一个 `https://xxx.vercel.app` 网址，自带 https。

### 2.4 部署完成检查清单

- [ ] 用 https 打开网址，地址栏显示小锁，页面正常显示（不是 404、不是文件列表）
- [ ] 按 `F12` → `Application` → `Manifest`，能看到「技能鉴定刷题」「刷题」及图标
- [ ] 按 `F12` → `Application` → `Service Workers`，刷新一次后显示 `activated and running`
- [ ] 断网（或勾选 Offline）后刷新，页面仍能打开
- [ ] 手机上用 Safari 打开，能「添加到主屏幕」并全屏运行
- [ ] 随便答几题，关闭再打开，进度还在

## 3. iPhone「添加到主屏幕」步骤

1. 用 **Safari** 打开部署好的 https 网址（⚠️ 必须 Safari，微信/抖音等内置浏览器不行）；
2. 点击屏幕**底部中间的「分享」按钮**（方框 + 向上箭头）；
3. 在弹出的菜单里**向下滑动**，找到 **「添加到主屏幕」**；
4. 名称默认是「刷题」，可以改成「技能鉴定刷题」，点右上角**「添加」**；
5. 回到主屏幕，点新出现的图标 → 全屏打开、没有地址栏，和普通 App 一样。

注意事项：

- iOS 16 / 17 / 18 的菜单顺序略有差别，但都是「分享 → 添加到主屏幕」；
- **第一次必须联网打开并停留几秒**（等图标缓存和离线缓存完成），之后才能离线使用；
- **删除主屏幕图标会同时删除这个 App 的本地学习数据**，删之前一定先在「设置 → 导出备份」；
- 部署更新后，主屏幕 App 可能还是旧版：**上滑彻底关闭 App 再打开 1～2 次**；如果仍不更新，删掉图标重新添加（同样先导出备份）；
- 主屏幕图标有时会延迟更新（iOS 缓存），属于系统行为，重新添加即可。

## 4. 单文件版 `dist/技能鉴定刷题.html`

### 4.1 它是什么

把 HTML、CSS、JS、600 题题库、图标**全部塞进一个 `.html` 文件**，双击就能用：不需要服务器、不需要网络、不依赖任何其它文件，也不会有任何相对资源请求。

### 4.2 怎么生成

在项目文件夹执行（需要 Python 3）：

```bash
python tools/build_single.py
```

- 默认读取 `index.html`，输出 `dist/技能鉴定刷题.html`；
- **交付包里的 `dist/技能鉴定刷题.html` 已经生成好了（约 332 KB），可以直接用**；
  只有当你修改了前端文件后才需要重新运行本命令；
- 想零警告再交付，可以加 `--strict`（有警告就失败，不输出文件）；
- 自定义输入输出：`python tools/build_single.py --input index.html --out dist/技能鉴定刷题.html`；
- 文件约 330 KB 左右（题库内联），打开稍慢是正常的。

### 4.3 怎么用

- **电脑**：直接双击这个 HTML 文件，浏览器打开即可刷题；
- **发到手机**：通过微信 / QQ / 邮件 / AirDrop 发过去 ——
  - 更稳妥的做法是：把文件放到「文件」App 后用支持的浏览器打开；
  - ⚠️ iOS 的「文件预览」环境对 `localStorage`（学习记录）支持不稳定，而且**不能添加到主屏幕**，
    所以单文件版在 iPhone 上只建议**临时查看/演示**，不适合长期做题。

> 想在 iPhone 上长期使用，请务必使用第 2 节（部署到 https）+ 第 3 节（添加到主屏幕）。
> 单文件版的价值：断网环境、U 盘拷贝、发给不会部署的人、没有服务器时的应急方案。

### 4.4 单文件版的限制

- 没有 Service Worker（`file://` 不允许），所以没有「离线缓存」这一层（但它本身就不需要网络）；
- 不能「添加到主屏幕」，没有系统级 App 体验；
- 学习记录同样保存在浏览器本地，换浏览器/清缓存会丢，记得导出备份（如果界面提供）。

## 5. 离线与缓存说明（PWA 原理，一句话版）

- 第一次联网打开 → 浏览器把核心文件存进缓存 → **之后断网也能打开和刷题**；
- 需要网络的情况：第一次打开、部署更新后重新拉取、换设备第一次打开；
- **局域网 http（`http://192.168.x.x`）不会注册 Service Worker**，属于正常现象，刷题照常，但没有离线缓存和安装能力；
- Safari 的「无痕浏览」模式下 Service Worker 和存储都不稳定，请勿使用。

### 更新版本（给维护者）

1. 修改了 `index.html` / `styles/app.css` / `src/*.js` / `icons/*` 等任何文件后，
   打开 `sw.js`，把 `const CACHE_VERSION = 'skillquiz-v20261031';` 改成新版本，
   例如 `'skillquiz-v20261101'`（当前交付值就是 `skillquiz-v20261031`，旧的缓存会自动清理）；
2. 重新部署；
3. 用户彻底关闭 App 再打开 1～2 次即可拿到新版本。

> 忘记改版本号 = 用户可能一直看到旧页面，这是 PWA 最常见的问题。

## 6. 学习数据存在哪？怎么备份（重要）

- **只存在当前设备、当前浏览器里**（`localStorage`，键名 `skillquiz.v1`），不上传、不同步；
- 以下情况会**丢失数据**：
  - 清除 Safari 网站数据 / 系统「清除历史记录与网站数据」；
  - **删除主屏幕图标**（iOS 会连带删除该 App 的数据）；
  - 换手机、换浏览器、换网址（不同域名的数据互不相通）；
  - 无痕/隐私浏览模式；手机空间极满时系统也可能清理网站数据。
- **备份**：进入 App「设置 → 导出备份」，会得到一个 `.json` 文件，保存到「文件」App / 网盘 / 微信文件传输助手；
- **恢复**：在 App「设置 → 导入备份」选择该文件即可；
- **建议**：每周或每学完一个阶段导出一次；**换手机、删除图标、重新部署前必须先导出**。

## 7. 常见问题（FAQ）

**Q1：改了内容，手机上还是旧的？**
A：把 `sw.js` 的 `CACHE_VERSION` 改成新值 → 重新部署 → 主屏幕 App 上滑彻底关闭再打开 1～2 次。仍不行就删图标重新添加（先导出备份）。

**Q2：主屏幕图标不更新 / 变白 / 还是旧图标？**
A：删除图标重新添加；确认 `icons/apple-touch-icon.png` 已更新；iOS 对图标缓存很顽固，必要时改一下图标文件名让地址变化。

**Q3：双击 `index.html` 白屏？**
A：用第 1.2 节的 http 服务打开，按 `F12` 看控制台报错；检查 `src/`、`styles/`、`icons/` 是否和 `index.html` 在同一目录结构里。

**Q4：添加到主屏幕后没有离线？**
A：第一次必须**联网完整打开并停留几秒**；确认网址是 https；确认不是无痕模式；`F12 → Application → Service Workers` 查看是否 `activated`。

**Q5：换网址/重新部署后数据没了？**
A：数据与「域名 + 端口」绑定，换地址就是新的存储空间。旧地址先导出备份，新地址再导入。

**Q6：在微信里打开能刷吗？**
A：能看到页面，但微信内置浏览器**不能添加到主屏幕**，且存储可能不稳定。请点右上角「…」→「在浏览器中打开」→ 用 Safari。

**Q7：更新代码/重新部署会清空我的学习记录吗？**
A：不会。部署更新不影响 `localStorage`；只有清除网站数据 / 删除主屏幕图标才会丢。

**Q8：单文件版能添加到手机主屏幕吗？**
A：不能（`file://` 不支持 PWA 安装）。要主屏幕体验，请用第 2 节 + 第 3 节。

**Q9：页面提示「离线不可用」「未注册 Service Worker」？**
A：多半是通过 `file://` 双击或局域网 http 打开的，属于正常降级，不影响刷题和记录保存。

**Q10：以后怎么改题、加功能？**
A：修改对应文件 → 运行 `python tools/build_single.py` 重新生成单文件版 → 修改 `sw.js` 版本号 → 重新部署。

**Q11：部署后打开是 404 或文件列表？**
A：`index.html` 没有放在网站根目录。请把整个文件夹的内容作为网站根目录（或子目录第一层）上传。

**Q12：iPhone 上添加到主屏幕后，底部或刘海区域被遮挡？**
A：正常情况下页面已适配安全区；如果异常，请确认部署的是最新版，并在 Safari 中强制刷新后再添加到主屏幕。

## 8. 维护者速查

```bash
# 重新生成图标（5 个尺寸，确定性输出）
python tools/gen_icons.py

# 生成单文件版（--strict 表示零警告才通过）
python tools/build_single.py --strict

# 本地预览（完整 PWA 能力）
python -m http.server 8000
```

| 改动内容 | 必须做的事 |
|---|---|
| 任何页面 / 样式 / 脚本 / 题库 | 改 `sw.js` 的 `CACHE_VERSION`，重新部署 |
| 只改单文件版 | 重新运行 `tools/build_single.py` |
| 改图标 | 运行 `tools/gen_icons.py`，再改 `CACHE_VERSION` |
| 改 PWA 名称/主题色 | 改 `manifest.webmanifest`（`theme_color` 与页面配色保持一致） |

> 图标主色：`#2E6BFF`；PWA 主题色 `theme_color: #F2F4F8`（与页面浅色主题一致）；启动背景色 `background_color: #F2F4F8`。
> 若以后调整界面配色，记得同步修改 `manifest.webmanifest` 的这两个颜色与 `index.html` 里的 `theme-color`。
